# Drop your images here

Anything you put in this folder (`apps/web/public/assets/`) is served
as-is at `/assets/<filename>` — no import statements, no build step.

Examples:
  apps/web/public/assets/logo.png        ->  <img src="/assets/logo.png" />
  apps/web/public/assets/bank-icon.png   ->  <img src="/assets/bank-icon.png" />
  apps/web/public/assets/avatars/king.png -> <img src="/assets/avatars/king.png" />

This is where all your AI-generated illustrations, avatars, dice renders,
and the board's bank building graphic will eventually live.
